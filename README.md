# MIT 8103 Advanced Database Systems Portfolio

## Project Title

**Fabbyent E-commerce Order Management System**

## 1. Case Study and Organisation

Fabbyent is a simulated e-commerce business that allows customers to browse products, place orders, make payments, and track deliveries. The system supports the management of product information, inventory, customer records, and order fulfilment.

## 2. Database Users

The main users of the database are:

- **Customers:** Browse products, place orders, and view their order and delivery status.
- **Administrators:** Manage products, categories, customer records, and system operations.
- **Inventory Staff:** Maintain stock records and update product availability.
- **Order-Processing Staff:** Process orders, record relevant payment information, and coordinate deliveries.

## 3. Major Data

The database will manage customer records, products, product categories, inventory, orders, order items, payments, and deliveries.

## 4. Key Database Operations

The system will support customer registration, product browsing, order placement, stock updates, payment recording, order-history retrieval, and delivery tracking.

## 5. Portfolio Activities

This repository will contain practical evidence for the five activities required by MIT 8103:

1. Database Design and Modelling
2. Query Processing and Optimisation
3. Transactions and Concurrency
4. NoSQL and Advanced Data Models
5. Distributed and Cloud Database Exercise

Implementation scripts, diagrams, test results, screenshots, and technical explanations will be added as each activity is completed.
